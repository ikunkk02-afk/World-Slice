# World Slice

**一个可配置、逐块精确的 Minecraft「世界切片」模组。**

World Slice 将 Minecraft 世界重新诠释为一道狭窄的垂直截面：X 轴变成可配置的深度，Z 轴则在两个方向上无限延伸。完整的原版建造高度——地形、洞穴、矿物、结构、生物群系，乃至末地龙战——都被完整保留在切片之内。

## 概述

World Slice 包裹原版的 Overworld、Nether 与 End 区块生成器，只生成一段连续的 X 列带。最终得到的，是一个侧向观看时如同 2D 切片的世界——类似泰拉瑞亚的视角——同时在可玩区域内完全忠实于原版 Minecraft 的生成。

核心特性：

- **三个维度共享同一厚度**。
- **纵向保真**——正常的建造高度、地形形态与洞穴系统均保持不变。
- **无限 Z 轴**——世界在前后方向上无限延伸。
- **不删除世界数据**——既有的区块与区域文件永远不会被批量删除或重写。

## 特性

- **可配置的世界宽度**，X 轴范围 1–4096 格（默认 16）。
- **三个原版维度**全部被切片，并共享同一厚度。
- **原版生成**——生物群系、地形、洞穴、含水层、矿物、植被、结构与刷怪均在切片内保持完整。
- **虚拟流体边界**，阻止水、岩浆及其他 `FlowingFluid` 实现流出切片。
- **隐形实体边界**，阻挡玩家与普通生物，同时放行末影龙与非生物实体。
- **泰拉瑞亚式侧面镜头**，带平滑实体插值，按 `V` 切换。
- **NeoForge 配置界面**，可从模组列表与游戏内打开。

## 核心概念

World Slice 重新定义了水平两个轴的含义：

| 轴 | 作用 |
|:--:|------|
| **X** | 切片深度——受配置的世界厚度限制。 |
| **Z** | 主要行进方向——双向无限延伸。 |
| **Y** | 高度——完整保留，从基岩到建造上限。 |

可玩区块范围为：

- **Overworld / Nether：** `X = 0 … thickness - 1`
- **末地：** `X = -(thickness / 2) … minX + thickness - 1`（以 `X = 0` 为中心）

例如，当 `thickness = 16` 时，Overworld 覆盖 `X = 0 … 15`，末地覆盖 `X = -8 … 7`。当 `thickness = 1` 时，世界只有一列，即 `X = 0`。

## 环境要求

- **Minecraft** 1.21.1
- **NeoForge** 21.1.249 或兼容的 NeoForge 21.1 版本
- **Java** 21

## 安装

1. 为 Minecraft 1.21.1 安装 NeoForge。
2. 下载 World Slice 发布版 JAR。
3. 将 JAR 放入实例的 `mods` 目录。
4. 启动游戏并创建或打开一个世界。

世界会立即被切片，无需任何额外设置。

## 快速上手

- 按 **`V`** 切换侧面镜头。
- 在游戏中按 **`O`** 打开设置界面。
- 从主菜单打开 **Mods → World Slice → Config** 修改默认值。
- 沿 **Z** 轴行走即可旅行；**X** 轴是狭窄的切片深度。

## 配置

三个入口打开的是**同一套**设置界面设计：

| 入口 | 上下文 |
|------|--------|
| **Mods → World Slice → Config** | 主菜单（未加载世界） |
| **`O`** 键 | 游戏内 |
| **暂停菜单 →「World Slice Settings」** | 游戏内 |

### 世界厚度（游戏内）

- **类型：** 每个世界独立的服务端设置。
- **存储：** Overworld 的 `SavedData`（`worldslice_settings`），由 Overworld、Nether 与末地共享。
- **范围：** 1–4096 格。
- **权限：** 在多人游戏中，仅权限等级 2 及以上的管理员可修改。

### 新世界默认厚度（主菜单）

- **类型：** 客户端可编辑的默认值。
- **存储：** `config/worldslice-common.toml`（`defaultWorldThickness`）。
- **语义：** **仅在** 全新 World Slice 世界首次初始化其世界设置时读取一次。既有世界保留各自的厚度，不受修改此值影响。

### 侧面镜头距离

- **类型：** 客户端设置。
- **存储：** `config/worldslice-client.toml`（`cameraDistance`）。
- **范围：** 8–64 格（默认 28）。
- **语义：** 仅影响本地客户端；不影响服务端或其他玩家，且在侧面镜头激活时可即时预览。

厚度修改会立即作用于三个维度的边界、碰撞、流体与渲染逻辑。新生成的区块使用当前设置；既有的区块与区域文件永远不会被删除或批量重写。

## 世界边界规则

World Slice 强制执行两条**相互独立**的边界：

1. **流体边界**——阻止水、岩浆（及其他任何 `FlowingFluid` 实现）扩散出切片。
2. **实体边界**——切片外侧的两道隐形虚拟碰撞墙。

### 实体边界矩阵

| 实体类型 | 行为 |
|----------|------|
| 玩家（生存 / 创造 / 冒险） | **阻挡** |
| 玩家（旁观） | 放行 |
| 普通生物——怪物、动物、村民、傀儡 | **阻挡** |
| Boss——凋灵、监守者、远古守卫者等 | **阻挡** |
| **末影龙** | **放行**（显式排除） |
| 掉落物实体 | 放行 |
| 经验球 | 放行 |
| 弹射物——箭、雪球、三叉戟、药水 | 放行 |
| 抛出的物品 | 放行 |
| 末影水晶 | 放行 |
| 载具——船、矿车 | 放行 |

实体边界是一道**安全边界**，而非真实的屏障方块。它依赖原版碰撞系统：当被阻挡的实体向边缘移动时，其 X 轴速度分量被消除，而 Y 与 Z 向移动继续正常进行，因此实体会沿墙滑行，而不是原地冻结。永远不会创建 `Barrier` 方块、保存实体或持久的墙区块。

末影龙被刻意豁免，因为其原版战斗需要完整的三维竞技场；它的飞行路径、AI 阶段与速度永远不会被 World Slice 修改。

## 各维度行为

### Overworld 与 Nether

- 从 `X = 0` 开始切片。
- 与末地共享同一厚度。

### 末地

- 围绕原版龙战原点（`X = 0, Z = 0`）**对称切片**。
- 中央基岩返回传送门因此始终位于切片中心。
- 龙战、末影水晶、龙复活、龙蛋与末地网关继续沿用原版流程（返回传送门在龙被击败前保持关闭）。

### 从旧版本升级

末地切片原点已改为以 `(0, 0)` 为中心。为获得正确居中的末地：

- 优先使用**尚未进入过末地**的世界，或
- 备份并删除旧的 `DIM1` 数据以重新生成。

World Slice 永远不会自动删除玩家的维度数据。

## 传送门行为

### 下界传送门

下界传送门保留原版 Z 轴 **8:1 缩放**，但从不把 X 当作水平距离缩放。X 是切片深度，因此在 Overworld 与 Nether 之间穿越时，玩家保持在相同的深度（并夹取到共享边界内）。自动创建的下界传送门使其宽度沿 Z 方向，这样即使 `worldThickness = 1`，框架也能保持在单一 X 列内。

### 进入末地

到达位置与黑曜石平台被重新定位到切片中心 X（末地为 `X = 0`），并将约 100 格的距离从龙战中心转移到开放的 Z 轴上。玩家到达 **`Z = 100`**，并沿 Z 轴前往 `(0, 0)` 的返回传送门。

### 末地返回传送门与网关

末地返回传送门位于切片中心的 `(0, 0)`。末地网关保留其计算出的 Z 坐标，并将 X 夹取到切片内。击败末影龙后返回 Overworld 继续沿用正常的床 / 世界出生点逻辑。

## 实现说明

### 生成器包裹

World Slice 在每个维度的服务端区块源构建时，包裹既有的 Overworld、Nether 与 End `ChunkGenerator` 实例，因此每个维度都保留自己的噪声设置、生物群系来源、高度与种子。只有与配置区块范围相交的区块才委托给原版生成管线；依赖区块继续通过正常的区块状态创建流程，而不进行地形、雕刻器、特性、生物或结构的放置。边界区块先运行原版生成，再裁剪到有效列，从而避免「先大片生成再删除」的情况。

### 集中式边界

所有区块、流体与实体边界都集中在 `WorldSliceBounds` 中，它暴露一个维度感知的 `SliceBounds` 值（`minX`、`maxX`、`centerX`、`thickness`）。在切片之外，方块与流体读取会暴露虚空 / 空状态，写入则会在加载越界区块之前被拒绝。

### 碰撞

`EntityMixin` 在 Minecraft 1.21.1 的 `Entity.collectColliders` 返回处注入，并在切片外侧添加两个有限 Z 的 `VoxelShape` AABB，覆盖整个建造高度。`WorldSliceBounds.affectsBoundaryCollision` 是决定哪些实体接收墙壁的唯一闸口。

### 服务端安全网

一个低频、仅针对玩家的安全检查会把直接传送、传送门及其他越界位置变化夹回玩家区间内。普通移动永远不会实现为逐刻传送，也不会对全部生物进行逐刻扫描。

## 已知限制

- 侧面镜头基于透视投影；镜头与玩家之间的前景地形仍可能遮挡玩家（尚未启用前景透明）。
- 尚未包含真正的正交投影，以及可选的真正 2D 移动模式。
- 跨越配置边界的世界特性与结构会在虚拟边界处被裁剪。
- 末地网关保留其计算出的 Z 坐标并将 X 映射进切片，但不会重新搜索安全落点；若映射列没有地形，玩家可能需要飞行。

## 从源码构建

```bash
./gradlew build
```

生成的 JAR 位于 `build/libs/worldslice-<version>.jar`。
